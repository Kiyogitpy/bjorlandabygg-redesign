# Before / after pairs

Drop real photos here (same framing, ideally 3:2, at least 1400px wide), then list them in `pairs.js`:

```js
window.BA_PAIRS = [
  { before: "kok-before.jpg", after: "kok-after.jpg" }  // optional: caption_sv, caption_en
];
```

An empty list hides the section. The test-* photos are placeholders: delete them and their entries before launch.
